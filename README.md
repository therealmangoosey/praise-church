# Praise Harvest Community Church

A responsive static website for Praise Harvest Community Church in Southampton.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Details shown on the site

- Sunday service: 10:00am
- Cantell School, Violet Road, Southampton, SO16 3GJ

The original Emergent export is retained in the repository ZIP as a source backup. The live-ready static page is `index.html`.

# Temporary photo upload folder

Upload the church photos you want added to the website into this folder.

You can upload multiple image files here using GitHub's **Add file → Upload files** option.

Please do not rename or organise them yet. Once uploaded, tell ChatGPT and I will:
1. Review each photo and identify what it shows.
2. Match photos to the most suitable sections of the Praise Harvest website.
3. Optimise image sizes and formats where appropriate.
4. Update the website to use the selected photos.
5. Remove this temporary upload folder once the images have been placed.

Supported formats: JPG, JPEG, PNG, WEBP.

This folder is temporary; the images will be moved into the website's permanent asset location after review.
